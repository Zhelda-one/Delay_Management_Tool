Introduction
============

`BBA (BaseBand Analyzer) <https://nok.it/bba>`_ is an interactive internal tool that helps with post-processing, analyzing, visualizing and generating signals. 

Watch our short `introduction video <https://engage.cloud.microsoft/main/org/nokia.com/threads/eyJfdHlwZSI6IlRocmVhZCIsImlkIjoiMjgyNzI4NDM0NzczMTk2OCJ9?trk_copy_link=V2>`_ for a quick overview of BBA's features!


About BBA
----------------------
  
    * BBA - BaseBand Analyzer;​
    * available at: `nok.it/bba <https://nok.it/bba>`_;​
    * an interactive internal tool to help post-process, analyze, visualize and generate signals;​
    * the files are analyzed locally in the browser (no installation required);​
    * the tool is written in JavaScript, the source code is available at https://wrgitlab.int.net.nokia.com/bbanalyzer/bba;​
    * a command-line version (NodeJS) can be generated;​
    * supports many capture file formats used in Nokia;​
    * optimized for Chrome and Edge, also works on Firefox.


Common use cases
-------------------------

    * checking validity of the baseband signal;
    * checking data alignment;
    * checking completeness and consistency of eCPRI transmission;
    * visualizing the data;
    * analyzing synchronization and timing of packets;
    * analyzing L2L1 message flow;
    * supporting pronto investigation. 

Features​
------------

    * file type autodetection;​
    * eCPRI dynamic compression/IQ bit width/compression method autodetection during file preload;​
    * eCPRI numerology/max numerology autodetection;​
    * L2L1 version autodetection.
